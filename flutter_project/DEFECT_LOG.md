# Academic Project Defect Log – Smart Quiz Application

| Defect ID | Severity | Module / Screen | Description | Root Cause | Resolution Status | Verified In Test |
|-----------|----------|-----------------|-------------|------------|-------------------|------------------|
| **DEF-01** | High | `QuizScreen` | Repeated fast taps on an answer option allowed score inflation. | `selectOption()` and `submitAnswer()` were not guarded by an `isAnswerSubmitted` lock. | **Resolved**: Added boolean gate locking answers immediately upon submission. | `test/widget_test.dart` (Test 2) |
| **DEF-02** | High | `AddQuestionScreen` | Users could submit duplicate options (e.g. Option A = Option B = "True"), creating invalid MCQs. | Form only checked for non-empty text, not uniqueness. | **Resolved**: Added set cardinality check `distinctSet.length == 4` with custom snackbar alert. | `test/widget_test.dart` (Test 3) |
| **DEF-03** | Medium | `QuizService` | OpenTDB returned HTML encoded entities (e.g. `&#039;`, `&quot;`) displaying corrupted text on screen. | API returns raw HTML escaped characters. | **Resolved**: Integrated `HtmlUnescape` utility to clean both question prompts and option choices. | Manual API verification & tests |
| **DEF-04** | High | `QuizScreen` | App threw an unhandled exception when OpenTDB rate-limited requests (HTTP 429) or when offline. | Network request had no try/catch fallback mechanism. | **Resolved**: Wrapped in resilient 4-second timeout with automatic fallback to high-quality offline question repository. | Verified offline in airplane mode |
| **DEF-05** | Medium | `QuizScreen` | Accidental back swipe or Android back button press closed quiz and wiped student's progress without notice. | Scaffold lacked back navigation interception. | **Resolved**: Wrapped root in `PopScope` presenting Material 3 exit confirmation dialog. | UI test in Android emulator |
| **DEF-06** | Low | `ProfileScreen` | Total accuracy calculation produced `NaN%` when user had 0 completed quizzes. | Division by zero when `totalQuestionsAnswered == 0`. | **Resolved**: Added guard `if (totalQuestionsAnswered == 0) return 0.0;`. | Unit test & UI render check |
